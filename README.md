# 🏏 IPL Sports Analytics

An end-to-end IPL analytics and match prediction platform built using Machine Learning and Power BI.

---

# 📌 Project Overview

This project analyzes IPL data from 2008–2024 to:

- Predict live match win probability
- Analyze player performances
- Compare team statistics
- Identify venue trends
- Visualize cricket insights using dashboards

---

# 🎯 Objectives

- Build real-time IPL win prediction system
- Perform player and team analytics
- Develop interactive dashboard
- Apply machine learning models on sports data

---

# 📂 Dataset

Datasets used:

- IPL Ball-by-Ball Dataset
- IPL Matches Dataset
- Cricsheet Data

Sources:
- Kaggle
- Cricsheet.org

---

# 🧠 Machine Learning Models

| Model | Purpose |
|---|---|
| Logistic Regression | Baseline prediction |
| Random Forest | Non-linear pattern recognition |
| XGBoost | Main win prediction model |
| K-Means Clustering | Player segmentation |
